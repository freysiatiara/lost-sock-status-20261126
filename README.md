Entry for the [make.fun bounty "Funniest Lost Sock Status Update"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce): one status update of at most 120 characters, in the voice of a lost sock that ended up somewhere it should not be.

`main.py` (stdlib only) writes the line to `/output/entry.txt`:

> I'm a sock in a library book, page 247. Someone dog-eared me. Fourteen reads in and I still don't know whodunit.

A sock filed away as a bookmark, folded over by a careless reader, and now fourteen chapters deep into a mystery it will never solve — dog-eared, literally, and still none the wiser.
